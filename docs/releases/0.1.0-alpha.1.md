# Commeatus v0.1.0-alpha.1

This is the first runnable public alpha of Commeatus.

It is intentionally small: the release proves the native flow/policy architecture through a real TCP execution path before adding a large protocol surface.

## Included

- Linux x86_64 and Android arm64 release binaries
- SOCKS5 no-auth TCP CONNECT
- HTTP/1.x CONNECT
- IPv4 and IPv6 destinations
- operating-system DNS resolution for direct domain targets
- `DIRECT` and `REJECT` policy
- exact-domain, domain-suffix, exact-IP, CIDR and destination-port rules
- configuration validation via `commeatus check`
- strict resource limits and transactional configuration compilation
- bounded handshake and TCP connect behavior
- 256 active-session limit
- loopback-only unauthenticated listeners unless explicitly overridden

## Example

```text
version 1
listen socks5 127.0.0.1:1080
listen http 127.0.0.1:8080
default direct
rule reject domain-suffix ads.example
rule reject cidr 10.0.0.0/8
```

Validate:

```bash
commeatus check --config commeatus.conf
```

Run:

```bash
commeatus run --config commeatus.conf
```

## Important security note

This alpha has no SOCKS5 or HTTP proxy authentication. Non-loopback listeners are rejected by default. `allow-public-listen true` is an explicit opt-out of that safety guard and should not be used on an untrusted network without another access-control layer.

## Not in this release

UDP, TUN, TProxy, eBPF interception, Android Root module packaging, proxy-protocol outbounds, DoH/DoT/DoQ, Fake-IP, rule providers, Clash/mihomo/sing-box import and adaptive routing are not part of this alpha.

The current blocking thread-per-session backend is deliberately transitional. The Android-focused low-power executor comes later.
